# Supplied Asset Manifest

Audit date: 2026-07-13

## Scope and handling

The workspace contains **43 supplied reference images** (38 `.jpeg`, 4 `.jpg`, and 1 `.png`; 15.23 MiB total). Every image was opened and visually inspected; dimensions and formats were read from the files. The originals remain untouched in the repository root.

All files are **single still images**, not sprite sheets, so their frame layout is `1 × 1`. Dimensions below are stored pixel dimensions. “Supplied photograph” describes the apparent medium, not verified authorship or permission. No creator, licence, subject-consent record, source URL, image-generation prompt, or model information accompanied the files. Apparent synthetic/composite status is therefore a visual assessment, not metadata proof.

Use these files as private development references unless rights are confirmed. V2 production derivatives should:

- be newly rendered in the project’s original retro-noir style rather than shipping raw photos;
- remove or fictionalise faces in incidental group shots, vehicle plates, institutional notices, brands, logos, badges, and readable clinical documents;
- avoid reproducing the AC/DC and Vegemite marks or identifiable car marques as game art;
- strip metadata, use fictional identifiers, and retain consent/provenance notes for any likeness that is published;
- export browser-ready WebP/PNG atlases while retaining replaceable character definitions and high-quality working masters outside the runtime bundle.

No supplied image is a finished sprite sheet, atlas, transparent cut-out, foreground occlusion layer, normal/depth map, or browser-optimised game background. Those must be designed as original V2 assets and recorded in an expanded production manifest with prompt/generation provenance, dimensions, atlas layout, compression settings and replacement identifiers.
